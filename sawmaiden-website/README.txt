SAWMAIDEN - SELF-HOSTED DESIGN GALLERY

QUICK START
1. Unzip the website package.
2. Upload the contents of the sawmaiden-website folder to your website's public folder.
3. Visit that folder's web address. index.html is the home page.

Keep index.html, styles.css, app.js, assets/ and downloads/ together.
You can host it at your domain root or in a subfolder such as /sawmaiden/.
All paths are relative. No build step, installation, account, database or backend is required.
Any web host that serves ordinary HTML and static files can host it.
The included PDF is about 34 MB; your host must allow files of that size.

LOCAL PREVIEW
Double-click index.html. All designs and downloads are available offline.
For sharing with someone else's phone or computer, upload it to your web host and send its URL.

WHAT VISITORS CAN DO
- Browse all ten concepts on mobile or desktop.
- Filter original-logo directions and subtly refined directions.
- Open an enlarged view; use Previous/Next or left/right arrow keys.
- Open the image in a new tab for browser zooming.
- Download or open the ten-page PDF.
- Download the transparent original logo as PNG, lossless WebP, or a ZIP with both.

DOWNLOAD BEHAVIOUR
Some mobile browsers open a PDF or image instead of immediately saving it.
Their Share / Save / Download option can then save the file. A ZIP download is
also provided for the two logo formats.

FILES
index.html        All page content and download links.
styles.css        Mobile and desktop layout.
app.js            Optional filters and enlarged-image viewer.
assets/           Compressed gallery previews and the lossless web logo.
downloads/        Original PDF, transparent logo files, and logo ZIP.

All ten concepts and download links remain available with JavaScript disabled.
There are no external fonts, scripts, analytics, forms, cookies or network services.
The PDF and downloadable logos are fetched only when a visitor follows a download link.

UPDATING THE SITE
Edit the wording or links in index.html, colours/layout in styles.css, and
replace the matching assets if artwork changes. Keep names and paths consistent.

DESIGN STATUS
The contact details shown in the mockups are fictional. These are visual concepts,
not final print artwork. The logo download is the cropped original direction;
the five subtle variations have not been exported as separate logo files.
