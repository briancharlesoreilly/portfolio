WOOD / FORM — SELF-HOSTED GALLERY

Upload index.html, style.css, gallery.js and the images folder together.
No installation, build step, account, or external services required.
You can also double-click index.html to preview it locally.

GITHUB PAGES
Copy this folder's contents into the folder your existing Pages site publishes
(usually the repository root or docs). Keep images beside index.html.
In your repository's Git console:
  git status
  git add .
  git commit -m "Publish Wood Form image gallery"
  git push
Wait for your GitHub Pages deployment to finish, then refresh the live site.
Check Settings > Pages if the published folder or branch is uncertain.

USE
Tap/click any image for the full image. Use Previous/Next, keyboard arrows,
or swipe left/right on the image. Escape or Close returns to the collection.
Image numbers link to credits at the end. Source inside the viewer does too.
